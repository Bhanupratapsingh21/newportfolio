## Overview

Linky is a powerful SaaS-based URL shortener built with modern web technologies. It provides secure authentication using JWT tokens and bcrypt, enables users to shorten URLs, and offers advanced analytics such as traffic insights, IP addresses, device types, and OS details. Users can also set multiple redirections for links and track their performance via a feature-rich dashboard.

## Technologies Used

- **Express.js**
- **Node.js**
- **TypeScript**
- **PostgreSQL**
- **Prisma ORM**
- **Bcrypt**
- **JWT**
- **Next.js**
- **ShadCN**
- **Aceternity UI**
- **Zod**
- **Redux**
